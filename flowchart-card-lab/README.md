# フローチャートカード ラボ（試作）

フローチャートカード教材を**つくり、ためし、直す**ための作業台です。高校の授業で使うフローチャートカードの問題を、**映像をまねる**と**遊んで見つける**の2通りで試せます。カードを並べて判定し、先生・作る係・見る係・遊ぶ係になりきって、気づいたことをメモできます。

- 公開中のページ：**https://109mei.github.io/flowchart-card-lab/**
- `index.html` の1ファイルだけで動きます。キャラ・物・背景の絵は **Kenney の CC0 素材**（Platformer Pack Redux・Space Shooter Redux）を埋めこんでいます（くわしくは `ASSETS_LICENSE.txt`）。カードの絵は図形（SVG）、音は Web Audio API で作っています。`og.png` は共有したときに出る画像、`icon-180.png` はスマホのホーム画面のアイコンです。字は Google Fonts の BIZ UDPゴシックです。
- スマホでも使えます。遊ぶときは、画面の矢印とスペースのボタンを押します（盤を押す・スペースキーでも、もう一度スタート）。
- 保存先は、開いたブラウザの中です（アカウント登録・サーバーはありません）。ほかの端末に持っていくときは「つくる → 書き出し・読み込み」で JSON に書き出します。

## 画面

| 画面 | できること |
|---|---|
| ホーム | 遊ぶ版「道わたり」の再生と、各画面の入口 |
| 問題集 | 14題（授業 v2.1 の10題・遊ぶ版3題・ジャムの例1題）と自分の問題。正解の並べ方・文・Python・配るカード。授業 v2.1 の印刷物の「ねこ・ボール」は、ここでは「ヒーロー・ジェム」と呼ぶ（並べ方と動きは同じ） |
| 遊ぶ・見る | 映像をまねる（決まった遊び方の再生）／遊んで見つける（矢印キーとスペースだけ） |
| 組む・ためす | カードを並べシートに置き、自分の並べ方で動かし、テストで判定し、お題とコマごとにくらべる。カードは流れ図の記号の形（もしはひし形）で、並べると線がつながり、はじめからおわりまでが1枚の流れ図になる |
| カード図鑑 | 授業の11種と遊ぶ版の6種、入れなかった候補。カードの言葉を変えられる |
| 模擬授業 | 授業の流れのタイマーと、教室のスクリーン用の投影画面 |
| つくる | 問題と授業の流れをつくる・直す、書き出し・読み込み |
| 気づきメモ | 不具合・足りないカード・分かりにくい所のメモ。まとめてコピーしてチャットに貼れる |

## 注意

- **試作です。生徒でも紙でもまだ試していません。** 遊ぶ版の問題・カード・授業の流れは企画案です。
- 作り方（元のソース・テスト）は、作者の研究データのフォルダ（`13_フローチャートカード企画/フローチャートカード_ラボ_20261025/作り方/`）にあります。このフォルダの `index.html` は、そこで作ったものをそのまま置いています。
