# フローチャートカード 体験ラボ（試作）

高校「情報Ⅰ」のフローチャートカード授業を、**導入を考える先生が体験するためのページ**です。見る係がゲームの動きを言葉で伝え、作る係がフローチャートカードを並べ、並べたとおりに動くかをアプリで確かめる授業を、次の2通りで体験できます。

- **ひとりで体験する**（約10分）：見る係 → 作る係 → 答え合わせを1人で進めます。次に押すところを黄色く光らせて案内します。
- **研修で模擬授業をする**：説明する人がこのページをスクリーンに映して進め、参加する先生が生徒役になります。カードは紙でも端末（参加者の画面）でも並べられます。

- 公開中のページ：**https://109mei.github.io/flowchart-card-lab/**（参加者の画面は最後に `#join` をつけたアドレス）
- `index.html` の1ファイルだけで動きます。キャラ・物・背景の絵は **Kenney の CC0 素材**（Platformer Pack Redux・Space Shooter Redux）を埋めこんでいます（くわしくは `ASSETS_LICENSE.txt`）。カードの絵は図形（SVG）、音は Web Audio API で作っています。`og.png` は共有したときに出る画像、`icon-180.png` はスマホのホーム画面のアイコンです。字は Google Fonts の BIZ UDPゴシックです。
- PC でもスマホでも使えます。PC は上の帯、スマホは下のタブで画面を移ります。
- 保存先は、開いたブラウザの中です（アカウント登録・サーバーはありません）。ほかの端末に持っていくときは「教材づくり → つくる → 書き出し・読み込み」で JSON に書き出します。

## 画面

| 画面 | できること |
|---|---|
| ホーム | 入口2つ（ひとりで体験する・研修で模擬授業をする）。見本1のカードを上から実行して見せる動く流れ図、授業でやること、50分×2コマの流れ、1班のカード |
| 体験する | しくみ → 見る係（お題を3回まで再生）→ 作る係（見る係のことばを見ながら並べ、実行・判定）→ 答え合わせ（正解の並べ方・学ぶこと・文・Python） |
| 模擬授業 | 授業をえらぶ、はじめる前に（紙の班・端末の班〔参加者の画面の QR コード〕・スクリーン・班の分け方）、いまの場面（時計・1回の進め方・生徒役と先生役がすること）、スクリーン用の「お題を映す」「時計を映す」「QRを映す」 |
| 参加者の画面 | 模擬授業で生徒役の先生が使う、作る係の画面（`#join`）。スクリーンに出ているお題をえらんで並べる。正解と動画は出ない |
| 授業の中身 | お題（14題と自分の問題。正解の並べ方・文・Python・配るカード）とカード（17種と入れなかった候補）。授業 v2.1 の印刷物の「ねこ・ボール」は、ここでは「ヒーロー・ジェム」と呼ぶ（並べ方と動きは同じ） |
| 教材づくり | 組む・ためす、遊ぶ・見る（遊ぶ版の試案）、白紙から自由に組む、つくる、カードの一覧、気づきメモ。係（先生・作る係・見る係・遊ぶ係）になりきって試す |

右上の「メモ」から、どの画面でも気づいたこと（不具合・足りないカード・分かりにくい所）を書けます。メモは開いたブラウザに残るだけで、作者には届きません。「気づきメモ」の画面でまとめてコピーして、渡してください。

## 注意

- **試作です。生徒でも紙でもまだ試していません。** 実際の先生に体験・模擬授業をしてもらったこともまだありません。遊ぶ版の問題・カード・授業の流れは企画案です。
- 作り方（元のソース・テスト）は、作者の研究データのフォルダ（`13_フローチャートカード企画/フローチャートカード_ラボ_20261025/作り方/`）にあります。このフォルダの `index.html` は、そこで作ったものをそのまま置いています。
