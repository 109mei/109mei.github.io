# せーの！おたから

2人が同時に島を選ぶ、全8ラウンドの読み合いゲームです。操作の速さでは勝敗が決まりません。

1. 毎ラウンド、3つの島に「2・3・5」のおたからが1つずつ現れます。配置は試合のシードとラウンド番号で決まり、2人に同じものが見えます。
2. 相手に見せず、島を1つ選びます。ふつうに進むか、「よくばり」を使うかも決めます。
3. 2人の選択がそろったら同時に公開します。
4. 違う島なら、その島のおたからをそれぞれ獲得します。同じ島ならぶつかって、2人ともおたからは獲得できません。
5. 「よくばり」は各自、1試合に2回だけ。選んだ時点で残り回数を1つ消費します。相手と違う島なら、おたからに+3点。同じ島なら、自分の得点が−2点になります。得点が0未満になることはありません。ふつうの相手は減点されません。
6. 8ラウンド終了時、得点の高い人が勝ち。同点なら引き分けです。

- 両者の得点・残りのよくばり回数・公開済みの結果は公開情報です。
- 現在の選択は、2人が確定するまで相手に見せません。
- 先に確定しても有利にはなりません。先手・後手による得点差はありません。
- 練習相手は公開情報だけから選びます。あなたの現在の未公開の選択は参照しません。

## オンライン実装の注意

選択は試合ID・ラウンド番号・プレイヤー番号（0または1）・32バイトの暗号学的乱数と一緒にSHA-256でコミットします。2人分のコミットがそろってから公開し、ハッシュを照合してください。ラウンド外・重複・別の試合のメッセージを通信側で拒否してください。接続切断や公開拒否で自動的な勝敗は付けず、待機または試合中断として扱ってください。

このエンジンは不変なスナップショットを扱う純粋関数です。同じ過去状態に同じ選択を渡すと同じ結果を返します。そのため、古い状態を再実行する行為そのものを検知する台帳は持ちません。通信側が現在の試合ID・ラウンド・メッセージ受理状態を管理します。シードは2人が選択を始める前に合意してください。
