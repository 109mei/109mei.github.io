# エアホッケー

スマホの縦画面で遊ぶ、ブラウザのエアホッケーです。**CPU戦**と、友達のスマホと直接つなぐ**オンライン対戦**ができます。
必殺技とステージの仕掛けで、1試合ごとに展開が変わります。**7点先取**で勝ちです。

- ファイルは `index.html` の1つだけで動きます（画像・音声ファイルなし。絵はすべて図形、音はすべて Web Audio API で作っています）
- オンライン対戦の通信には PeerJS（WebRTC）を使います
- 公開中のページ：**https://109mei.github.io/airhockey/**

## 遊び方

### マレットの動かし方
- 画面に指を置くと、**指の少し上に自分のマレット（青）が現れます**。そこから**指を動かした分だけ**動きます。指でマレットが隠れません
- **指を離すとマレットは消えます**。消えている間、パックは素通りするので、守るときは指を置いたままにします
- 動けるのは**台の下半分（自分の陣地）**だけです
- **速く振って当てるとパックは速く飛び**、そっと当てると勢いが落ちます
- マレットを**引きながら受ける**と、パックをほぼ止められます

### 必殺技
- パックを弾くたびに**ゲージ**がたまります。ゲージは**画面の下の左右の三角形**です（液体が満ちていくようにたまります）。三角形の中には、選んだ技の**マーク**が出ます
- 満タンになると三角形が**金色に光ります**。左右どちらかの三角形を**タップ**すると発動します
- マレットを動かしている指とは別の指で押せます。**三角形の中で触り始めた指だけ**がボタンになるので、マレットの指が滑り込んでも発動しません
- 画面の上の三角形は**相手のゲージ**です。相手のゲージがたまっていく様子が見えます
- 試合の前に、使う技を1つ選びます

| 技 | マーク | 種類 | 効果 |
|---|---|---|---|
| 剛速球 | 炎の尾を引くパック | 攻撃 | 次のショットが炎をまとって超高速で飛ぶ |
| カーブ | 曲がる矢印 | 攻撃 | 次のショットが大きく曲がる（振った向きと逆へ曲がって戻ってくる） |
| 分身 | 3つに分かれる玉 | 攻撃 | 3つに分かれ、**どれか1つでも相手のゴールに入れば1点**。相手のマレットに触れた分身は消え、本物を打ち返されると分身はすべて消える |
| 消える球 | 点線で消えかけた玉 | 攻撃 | 次のショットが途中で見えなくなる |
| 稲妻 | 稲妻 | 攻撃 | 次のショットが左右にジグザグに折れ曲がる |
| ミニ球 | 内向きの矢印 | 攻撃 | 次のショットのパックが小さくなる（当たり判定も小さい） |
| 防壁 | 盾 | 守り | 自分のゴール前に数秒だけ壁が出る |
| 巨大化 | 外向きの矢印 | 守り | 自分のマレットが数秒だけ大きくなる |
| 衝撃波 | はじける輪 | 守り | 近くのパックを相手の陣地へ吹き飛ばす（マレットを出しているときだけ使える） |
| 重い腕 | 重り | 妨害 | 相手のマレットが数秒重くなる（動きが遅れ、強く打てない） |
| ゴール拡大 | 広がるゴール | 妨害 | 相手のゴールが数秒だけ広くなる |
| 反転 | 入れ替わる矢印 | 妨害 | 相手の左右の操作が数秒だけ逆になる |

技は**いきなり使われる**のが面白いので、発動の瞬間の演出や音はありません。ゲージが空になり、効いている間の様子（壁・大きなマレット・重り など）だけが見えます。攻撃の技を構えても、相手の画面ではゲージが満タンのまま見えるので、構えたことは撃つまで相手に分かりません。試合中に画面に出る言葉はゴールのときだけです（数字は点数・カウントダウン・ラリー回数だけ）。

**攻撃の技は、発動したあと次に弾いたショットにかかります**（自分のマレットと三角形のマークのまわりを輪が回っている間が「構え中」）。守りと妨害の技は押した瞬間に効きます。

### ラリー
- 両者が打ち返した回数を数えます（失点するとリセット）
- ラリーが続くほど、打ち返しが強くなり、パックの最高速度も上がります
- **ラリーが10回続くとパックが2個に**なります。どちらが入っても1点で、得点するとパックは1個に戻ります

### ステージ
| ステージ | 見た目 | 仕掛け |
|---|---|---|
| ピラーズ | 六角形のタイルの青い台 | 中央の柱と4つのバンパー |
| スイーパー | 鉄板の工場。中央にレールと誘導灯 | 中央線の上を壁が左右に往復する |
| スプリング | 蛍が舞う緑の森 | 左右の壁の一部がバネ。当たると速く跳ね返る |
| ブースト | 車線と縁石のサーキット | 矢印の床で加速、中央の氷の床でゆっくりに |
| ワープ | 星雲と渦の宇宙 | 左の壁の穴に入ると右の壁から出てくる |
| シャッター | コンクリートの要塞 | ゴールが一定の間隔で半分ふさがる（閉まる前に、ふさがる側が点滅し、ゴールポストのランプが光って予告） |
| ゴールゆらぎ | 心電図が走る緑のモニター | ゴールの幅が広がったり狭まったりする |
| 暗闇 | 泡が昇る深海 | マレットの周りしか見えない。パックは音で追う |

柱は八角形の金属の塊、バンパーは歯車のような土台に光の輪がついた形で、パックとは見分けがつくようにしています。床の模様や飾りには、仕掛けや自分・相手の色（青・赤）と紛らわしい色や形を使っていません。
仕掛けはすべて上下対称に置いてあり、どちらか一方が有利になりません。

**暗闇ステージ**では、パックはマレットの明かりに入ったときだけ見えます。パックが左にあれば左から音が聞こえ、自分のマレットに近いほど大きく、速いほど高い音になります。壁・柱・マレットなど、当たった物ごとに音も変わります。

### オンライン対戦
1. どちらか1人が「オンライン対戦」→「部屋を作る」を押します（この人がホストです）
2. 画面に出る**4文字の部屋コード**を相手に伝えるか、**招待リンク**を送ります（「リンクをコピー」「共有」ボタン）
3. 相手は「オンライン対戦」で部屋コードを入力して「参加」、または招待リンクを開くだけで参加できます
4. それぞれ必殺技を選び、ホストがステージを選ぶと試合が始まります
5. 試合のあとは「もう一度」で同じ設定のまま再戦、「技とステージを変える」で選び直しができます

どちらの画面でも、自分のゴールが下に来るように表示されます。ホストとゲストで画面の形が違っても、同じ形の台で遊べるよう、ゲスト側は台を縮小して表示します。

### そのほか
- 左上の「Ⅱ」ボタンで一時停止できます（オンライン対戦では止まりません）
- タイトルの「音：オン／オフ」で効果音を切り替えられます
- iPhone のマナーモード中でも音が鳴るようにしてあります（対応している環境のみ）
- ノッチのある機種や、ブラウザが画面の上にサイト名を出す環境でも隠れないよう、画面の上端は少し空けてあります（スマホのブラウザで開いたとき。幅は `index.html` の先頭の `GEO.TOP_GUARD` で変えられます）

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作ります（例：`airhockey`）。公開範囲は **Public** にします（無料プランで Pages を使う場合）
2. このフォルダの中身をそのリポジトリに置きます。`index.html` は**リポジトリの一番上の階層**に置きます
3. リポジトリの **Settings → Pages** を開きます
4. 「Build and deployment」の **Source** を **Deploy from a branch** にします
5. **Branch** を `main`、フォルダを `/ (root)` にして **Save** を押します
6. 1〜2分ほど待つと、`https://ユーザー名.github.io/リポジトリ名/` で遊べるようになります（同じ画面の上部にURLが表示されます）

招待リンクは、そのとき開いているページのURLから作るので、URLを書き換える必要はありません。

## うまくつながらないとき
- オンライン対戦は、PeerJS の公開サーバーで相手を見つけ、そのあとスマホ同士を直接つなぎます
- 携帯回線や会社・学校のネットワークによっては、直接つながらないことがあります。そのときは、両方を同じWi-Fiにする、片方をモバイル回線にする、などを試してください
- それでもつながらない環境向けに、`index.html` の先頭の `NET.ICE_SERVERS` に TURN サーバーを追加できます。自分で PeerServer を立てる場合は `NET.PEER_SERVER` に `{ host, port, path, secure }` を書きます

## 手触りの調整

`index.html` の**先頭**（`<head>` の中の最初のスクリプト）に、調整しやすい数値をまとめています。

| 定数 | 意味 |
|---|---|
| `TUNE.PUCK_MAX_SPEED` | パックの最高速度（台の長さ/秒） |
| `TUNE.RESTITUTION` | マレットとの反発の強さ（0.7） |
| `TUNE.RALLY_POWER_GAIN` / `RALLY_POWER_MAX` | ラリーでの打ち返しの強さの上がり方と上限 |
| `TUNE.RALLY_SPEED_GAIN` / `RALLY_SPEED_MAX` | ラリーでの最高速度の上がり方と上限 |
| `TUNE.SECOND_PUCK_RALLY` | パックが2個になるラリー回数 |
| `TUNE.GAUGE_PER_HIT` | 1回弾くごとにたまるゲージの量 |
| `TUNE.WIN_SCORE` | 勝利点数 |
| `TUNE.NET_SEND_HZ` | 通信の送信頻度（回/秒） |

ほかにも、台の寸法（`GEO`）、必殺技（`SKILL`）、ステージ（`STG`）、演出（`FX`）、CPUの強さ（`AI`）、通信（`NET`）の値があります。速さはすべて「台の長さ/秒」の単位なので、画面の形が変わっても体感は変わりません。

## ファイルの構成

```
index.html      ゲーム本体（これだけで動きます。公開に必要なのはこのファイル）
README.md       このファイル
build.js        src/ の部品を index.html にまとめる道具（node build.js）
src/            index.html の元になる部品
  template.html   HTMLのひな形
  style.css       画面の見た目
  body.html       メニュー画面
  js/             プログラム（番号順につなげる。00_config.js が先頭の定数）
tools/          開発用の自動テスト（Node.js と Playwright が必要）
```

`index.html` を直接書き換えてもかまいません。`src/` を書き換えた場合は `node build.js` で `index.html` を作り直します。
自動テストは `npm install playwright` のあと `sh tools/run_all.sh` で実行できます。

## 動作環境
- iPhone（Safari）、Android（Chrome）の最新版を想定しています。パソコンのブラウザでも、マウスでドラッグして遊べます
- オンライン対戦には、インターネットへの接続が必要です
