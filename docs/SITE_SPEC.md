## 1. 目的と対象

- 永野斗遠（ながの とわ／GitHub: 109mei）の業績・制作物・活動が一目でわかるポートフォリオ。
- 読む人: 大学・学会関係者、連携先（高校等）、就職・コンテスト関係者。
- 印象: 誠実で見やすい。そのうえで遊び心がある。

## 2. デザインコンセプト —「高度を上げる」

参考にした構造: 竹書房「メイドインアビス」公式サイトのアビスガイドページ（層を潜っていく縦構成・深度表示・層ジャンプ）。**著作物（画像・キャラ・固有名詞・意匠の模倣）は一切使わない**。仕組みだけを借り、世界観はオリジナル。

- このサイトは潜るのではなく**昇っていく**: 夜空・成層圏をテーマに、下にスクロールするほど「高度◯◯m」が上がり、経歴が積み上がっていく。
- ダークトーン基調（夜空の紺）＋星の粒（CSS/Canvasで自作、控えめ）。ライトモードでも破綻しない。`prefers-reduced-motion` でアニメーション停止。
- 単一ページ（`index.html`）＋データ分離（`data.js`）。依存パッケージなし・vanilla JSのみ。

## 4. 遊び要素・便利機能

### 4-1. 高度（このサイトの背骨）

**高度はピクセル位置から計算しない。** 内容に固定の値を割り当て、画面幅やフィルタ操作で数値が変わらないようにする（同じ出来事は常に同じ高度）。

| 位置 | 高度 |
|---|---|
| ヒーロー | 0 m |
| About | 1,000 m |
| 数字で見る活動 | 2,000 m |
| 年表の各項目 | 3,000 m 〜 9,000 m（項目ごとの固定値。`data.js` の `alt`。古い項目が低く、新しい項目が高い） |
| 業績一覧 | 10,000 m |
| 制作物 | 11,000 m |
| リンク／関連サイト | 12,000 m（**成層圏＝到達点**） |

- 画面端の高度メーターは、**読んでいる位置にある要素の高度**を表示する（要素と要素の間はなめらかに補間）。年表内では到達した年も併記する。
- 高度に応じて**層の名前**（地上／雲の下／雲の上／高層／圏界面／成層圏）と**背景の空の色**が変わる。潜るのではなく昇る、という§2のコンセプトをここで回収する。
- ページ末端（12,000 m）に到達したら、フッター手前で「成層圏 到達」を示す。

### 4-2. その他

- 数字のカウントアップ（§3-3）。
- 業績のフィルタ・キーワード検索・件数表示、書誌／BibTeXコピー、全件コピー（§3-5）。
- **印刷用CSS**: 印刷すると装飾が消えて業績一覧が白背景のきれいな一覧になる（提出資料に使えるように）。フィルタや検索で絞り込んでいても**印刷では全件出す**。
- ダーク/ライト切替ボタン（既定はOSの設定に従う）。
- **キーボード操作**: `j`/`k` で次／前のセクション、`g`/`G` で先頭／末尾、`/` で業績検索へ、`?` でショートカット一覧。入力中は無効。ショートカットの存在はフッターに明記する。

## 8. 技術要件（実装の約束）

**8-1. 対応ブラウザとフォールバック**

- `color-mix()`・`backdrop-filter`・`word-break:auto-phrase` は「あれば使う」扱いにし、**使えない環境でも成立する値を必ず先に書く**（半透明ヘッダーの背景が消えて文字が重なる、といった状態を作らない）。

**8-2. アクセシビリティ**

- タップ領域は最低44×44px（本文中のインラインリンクは除く）。
- 同じ文言のボタンを並べない（「書誌をコピー」は対象の題目を `aria-label` に含める）。
- フィルタ・検索の結果は読み上げ用に告知する。
- ページ内リンク先にフォーカスを移す。
- `:hover` だけに頼らず `:active`・`:focus-visible` も指定する。

**8-3. 失敗時の挙動**

- `data.js` の読み込み失敗・データ欠落時は、画面に日本語で状況を出す。

**8-4. 共有・検索対応**

- OGP画像（1200×630、`assets/og.png`）、`twitter:card`、`canonical`、`apple-touch-icon`、`robots.txt`、`sitemap.xml` を置く。
- 業績を構造化データ（JSON-LD: `Person` と各発表）で出す。データ源は `data.js` のみとし、二重管理しない。
- 英語併記は**§6に正式な英語題目が追記されてから**行う（現時点では未確定のため、UIラベルと氏名・所属のみ英語を併記する）。

**8-5. 表記ルール**

- `data.js` のデータはこの仕様書と同じISO表記（`2026-09-05`、`2026-02-28〜03-01`、`2025-05〜07`、`2026-08〜`）で持つ。
- 画面には日本語表記（`2026年9月5日`、`2026年2月28日〜3月1日`、`2025年5月〜7月`、`2026年8月〜`）で出す。変換は実装側で行い、データは書き換えない。
- 「年度」表記（`2024年度`）はそのまま出す。
