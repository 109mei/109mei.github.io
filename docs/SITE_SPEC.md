- 印象: 誠実で見やすい。そのうえで遊び心がある。

## 2. デザインコンセプト —「高度を上げる」

参考にした構造: 竹書房「メイドインアビス」公式サイトのアビスガイドページ（層を潜っていく縦構成・深度表示・層ジャンプ）。**著作物（画像・キャラ・固有名詞・意匠の模倣）は一切使わない**。仕組みだけを借り、世界観はオリジナル。

- このサイトは潜るのではなく**昇っていく**: 夜空・成層圏をテーマに、下にスクロールするほど「高度◯◯m」が上がり、経歴が積み上がっていく。
- ダークトーン基調（夜空の紺）＋星の粒（CSS/Canvasで自作、控えめ）。ライトモードでも破綻しない。`prefers-reduced-motion` でアニメーション停止。
- 単一ページ（`index.html`）＋データ分離（`data.js`）。依存パッケージなし・vanilla JSのみ。

- **掲載可**: 氏名（永野斗遠）、所属（九州情報大学大学院・荒平研究室・IDERIA代表）、出身校（嘉穂総合高等学校）、§6の確定業績、共同研究者の実名（田村明日香・荒平高章・椎葉圭・中嶋文萌・伊嵜音子 — 学会プログラム・受賞記録という公的情報の範囲で）。
